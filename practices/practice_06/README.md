## 🚀 Быстрый старт и проверка

### 1. Запуск автоматических тестов (`make test` / `make step6`)
```bash
# Из папки practices/practice_06:
make step6
# или:
make test
```
Все **26 тестов** (16 базовых функциональных + 10 регрессионных тестов безопасности) выполняются успешно со 100% результатом.

### 2. Запуск сервиса Mini Shop
```bash
make run
# либо из каталога lab/:
python3 lab/service.py --port 8066
```
Сервис поднимется локально на `http://127.0.0.1:8066`.

### 3. Запуск и тестирование MCP-сервера
MCP-сервер предоставляет инструменты для автоматического сканирования уязвимостей сервиса и оценки модели угроз по рубрикатору:
```bash
python3 mcp/test_client.py
# или прямой вызов:
python3 mcp/security_auditor.py --test
```

Конфигурация подключения к OpenCode / Claude Desktop / Antigravity:
```json
{
  "mcpServers": {
    "minishop-auditor": {
      "command": "python3",
      "args": ["/home/zhenya/ITMO/VibeCoding/ITMOv2/practices/practice_06/mcp/security_auditor.py"]
    }
  }
}
```

# Отчёт: локальные модели и агенты (Практика 3)

## Окружение

- **ОС:** Linux Ubuntu 24.04.5 LTS (ядро 7.0.0-38-generic, x86_64)
- **CPU:** AMD Ryzen 7 5700U with Radeon Graphics (8 ядер, 16 потоков, 1.8–4.38 ГГц)
- **GPU / VRAM:** Встроенное видеоядро AMD Radeon Graphics (UMA, общая системная память, инференс выполняется на CPU с оптимизациями AVX2/FMA)
- **RAM:** 30 GiB DDR4 (свободно/доступно > 20 GiB)
- **Свободный диск:** ~96 GB доступно на NVMe SSD
- **Версии ПО:**
  - Ollama: `v0.35.1`
  - LM Studio CLI: `lms 0.3.x`
  - OpenCode: `v1.18.33`
  - Python: `3.12.3`
- **Модель, разработчик, семейство, тег и ID:**
  - `qwen3.5:4b` (ID: `d8b0f5e9760c`, Alibaba Cloud, семейство Qwen 3.5, размер 3.3 GB)
  - На базе неё собраны агенты:
    - `itmo-agent:latest` (ID: `b44d41f574a1`, расширенный контекст 64k)
    - `itmo:latest` (ID: `94ff63f781e3`, контекст 4k, системный промпт проекта)
- **Формат, квантизация, лицензия, источник:**
  - Формат: GGUF
  - Квантизация: Q4_K_M (4-bit)
  - Лицензия: Apache 2.0
  - Источник: официальный реестр Ollama Library (`ollama pull qwen3.5:4b`)
- **Фактический контекст, размещение CPU/GPU:**
  - Контекст: `4096` токенов для вопрос-ответного помощника (`Modelfile`), `65536` токенов для автономного агента OpenCode (`Modelfile.agent`)
  - Размещение: 100% CPU RAM (3.3 GB веса модели + KV-кэш)
- **Почему выбрана эта конфигурация:**
  - Модель `qwen3.5:4b` с квантизацией Q4 идеально сбалансирована для ноутбука без дискретной видеокарты: размер всего 3.3 GB (легко помещается в 30 GB RAM), высокая скорость инференса (~8–10 токенов/сек на CPU) и отличное качество понимания русского языка и кода Python.

## Воспроизведение

1. **Запуск локального демона Ollama:**
   ```bash
   ollama serve
   ```
2. **Скачивание весов модели:**
   ```bash
   ollama pull qwen3.5:4b
   ```
3. **Сборка агентов из Modelfile:**
   ```bash
   cd practices/practice_03/lab
   ollama create itmo-agent -f Modelfile.agent
   ollama create itmo -f Modelfile
   ```
4. **Проверка эндпоинта и скачанных весов:**
   ```bash
   ollama list
   curl -s http://localhost:11434/v1/models
   ```
5. **Проверка работы в автономном режиме без сети:**
   Инференс полностью автономен, обращений к внешним серверам нет (`http://localhost:11434`).

## Выводы

1. **Борьба с галлюцинациями:**
   Введение строгого системного промпта (`SYSTEM "Если данных нет, напиши «В предоставленных материалах нет ответа»"`) полностью устраняет галлюцинации: модель не придумывает CI-пайплайны и корректно отвергает вопросы с ложными предпосылками.
2. **Ограничения CPU-инференса:**
   На процессоре AMD Ryzen 7 без дискретной GPU скорость инференса составляет ~8–10 токенов/сек. Это комфортно для диалогового ассистента, но для длинных рассуждений критически важно отключать `think: false` (внутренний Chain-of-Thought), иначе модель генерирует тысячи сервисных токенов размышлений перед выдачей ответа.
3. **Готовность OpenCode:**
   Агент `itmo-agent` с контекстом 64k токенов и правами `read/glob/grep` в `demo/opencode.json` полностью покрывает задачи локального инспектора кода без риска случайного повреждения файлов проекта.

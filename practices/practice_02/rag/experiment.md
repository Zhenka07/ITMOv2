## Запрос

```text
Вы — Compliance & Grounding Engineer. Работайте исключительно с разрешенными источниками (CASE.md, context.md, TRAINING_PR.diff).
Любая внешняя информация или предположение без ссылки на файл и строку запрещены.
Задача:
1. Сопоставьте каждый сценарий из tests_integration.md с нормативным правилом из CASE.md.
2. Укажите точные входные значения (например: длина строки для API-1, вид секрета для SEC-1, время таймаута для REL-1) строго по тексту источников.
3. Исключите любые непроверяемые или вымышленные требования.
```

## Ответ со ссылками на источники

1. **Валидация входа:** Запрос без схемы вызывает `KeyError` в строке [`TRAINING_PR.diff:37`](../../practice_01/TRAINING_PR.diff#L37). Согласно [`context.md:17`](../../practice_01/context.md#L17), тела запросов в FastAPI описываются Pydantic-моделями с автоматическим возвратом HTTP 422 при невалидном вводе.
2. **Лимит длины (API-1):** Согласно [`CASE.md:65`](../../practice_01/CASE.md#L65), diff длиннее 20 000 символов обязан отклоняться с HTTP 413 Payload Too Large. Тестовый вход: строка длиной 20 001 символ.
3. **Отказоустойчивость LLM (REL-1):** Согласно [`CASE.md:66`](../../practice_01/CASE.md#L66), внешний LLM-вызов имеет timeout ровно 10 секунд; ошибка преобразуется в контролируемый ответ (HTTP 504/502).
4. **Маскирование секретов (SEC-1):** Согласно [`CASE.md:64`](../../practice_01/CASE.md#L64), перед отправкой во внешний LLM из diff удаляются токены, пароли и приватные ключи с заменой на `[REDACTED]`.
5. **Нормализация ответа (OUT-1):** Согласно [`CASE.md:67`](../../practice_01/CASE.md#L67), ответ сервиса должен содержать поля `summary`, `risks` (максимум 3 элемента с полями `file`, `line`, `evidence`, `risk`) и `checks`.

# ReAct

- Цель: Автоматически локализовать дефекты в `project_management.md` (сломанный граф Mermaid, висящая задача без ID, шаблонный плейсхолдер), внести точечный патч и верифицировать результат вызовом `make step1`.
- Доступные входы: Файлы `practices/practice_01/project_management.md`, `practices/practice_01/CASE.md`, команда `make step1`.
- Разрешённые действия:
  - `read_file(path, start_line, end_line)`
  - `replace_file_content(path, target, replacement)`
  - `run_command(cmd)` (только linter и `make step1`)
- Запрещённые действия: Удаление файлов, изменение файлов вне scope, сетевые запросы, выполнение шагов без предварительного логического обоснования (Thought).
- Максимальное число шагов: 5.
- Условие остановки и вопроса человеку: Успешный запуск команды `make step1` и подтверждение связности графа Mermaid; если `make step1` падает с непредвиденной ошибкой — остановиться и запросить подтверждение человека.

## Запрос

```text
Вы — автономный ReAct-агент. Действуйте по циклу Thought -> Action -> Observation -> Decision.
Цель: Исправить разрыв зависимостей в диаграмме Ганта и удалить плейсхолдер в `project_management.md`.
Инструменты: read_file, replace_file_content, run_command (make step1). Лимит: 5 шагов.
```

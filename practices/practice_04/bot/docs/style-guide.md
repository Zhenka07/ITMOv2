# Style Guide проекта ReadAdviserBot

Краткие соглашения по стилю и оформлению кода.

1. **Тестируй через публичный интерфейс:**
   - Пиши тесты на публичные функции и методы (`ValidateURL`, `IsURL`, методы `Processor`), проверяя поведение системы снаружи, а не приватное состояние структур.

2. **Используй стандартные идиомы Go:**
   - Обработка ошибок через `if err != nil { return fmt.Errorf("...: %w", err) }`.
   - Имена интерфейсов — в стиле Go (действие + -er: `Storage`, `Fetcher`, `Processor`).
   - Используй табличные тесты (`table-driven tests`) для проверки граничных случаев функций валидации и парсинга.

3. **Не добавляй тяжелые зависимости:**
   - Не подключай внешние валидаторы или громоздкие фреймворки ради простых строковых операций или проверки URL.

4. **Чистота ресурсов и контекстов:**
   - Всегда пробрасывай `context.Context` в методы хранилища и сетевые вызовы.
   - Освобождай ресурсы (`Close()`, `defer`) при открытии соединений и файлов.
